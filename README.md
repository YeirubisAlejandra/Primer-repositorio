# Primer-repositorio# Comandos Git

| **COMANDO**  | **O QUE FAZ?** |
| --- | --- |
| git -v | verificar se o git está instalado |
| git init | inicializar o repositorio do git |
| git config --global user.name | verificar se o nome está configurado  ou configurar o nome |
| git config --global user.email | verifica a configuração do email ou adiciona o e-mail a configuração |
| git status| verificar o estado atual do repositporio. |
| git add livros.txt | Adiciona as mudanças no repositorio. |
| git commit -m “mensagem do commit”| registra a alteração no histórico do git. |
| git log | Mostra todas os registros do histórico. |
| git remote add origin url | Adiciona o git online (url) no origin . Sincronizar o git e github. adicionar o repositório local ao repositório remoto |
| git branch -M novo-nome-da-branch | altera a Branch do repositório de master para main ou vice-versa. |
| git push -u origin main | envia o repositório local (as alterações) para o repositório remoto |
